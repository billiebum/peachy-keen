# peachy-keen
Peachy Keen Theme

Version: 1.0
Author: Stephanie Fraser

Description:
Peachy Keen is a warm, soft-toned WordPress theme designed for personal blogs. It features a calm peach and sunset-inspired colour palette, clean typography, and a simple two-column layout with a sidebar.

The theme focuses on readability and a relaxed aesthetic, making it ideal for journaling, casual blogging, or personal websites.

Features:

* Responsive layout
* Sidebar with widgets
* Styled comment section
* Soft gradient header and navigation
* Clean, readable typography
* Tag styling and archive support

Installation:

1. Upload the theme folder to /wp-content/themes/
2. Go to Appearance → Themes
3. Activate “Peachy Keen”

Recommended Setup:

* Add a menu under Appearance → Menus
* Add widgets to the sidebar (Archives, Categories, etc.)
* Use featured images for best visual results

Notes:
This theme was built as a personal project and refined for usability and consistency. It aims to provide a simple, pleasant blogging experience without unnecessary complexity.
